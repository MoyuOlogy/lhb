# 龙虎榜 · 沪深主板（GitHub Pages 静态站）

纯静态页面 + GitHub Actions 定时抓取的每日龙虎榜站点。每个交易日**北京时间 20:00 / 20:30** 自动抓取当日龙虎榜，
列出每只上榜个股的**买入前五、卖出前五席位**（即买一到买五、卖一到卖五）及金额，
只收录沪深主板（600 / 601 / 603 / 605 / 000 / 001 / 002 / 003），并对**深股通买入**做金色高亮特别标注。

线上地址：`https://<你的用户名>.github.io/<仓库名>/`（以子项目形式托管）。

## 功能

- **今日页（index.html）**：只展示当日（数据未生成时自动回退到最近交易日）榜单；
  汇总卡片（上榜家数 / 净买合计 / 沪深股通买入 / 机构买入）；点击个股卡片展开买卖前五席位明细；
  支持按「深股通买入 / 沪深股通买入 / 机构买入 / 净买入 / 净卖出」筛选和代码名称搜索。
- **历史归档（history.html）**：按月分组的全部交易日列表，含每日上榜家数与净买额摘要。
- **日期详情（detail.html?date=YYYY-MM-DD）**：查看任一历史交易日，支持上一/下一交易日切换与日期下拉跳转。
- **深股通标注**：买方前五中出现"深股通专用"的个股，卡片右上带金色「深股通买入」标签，席位行金色高亮；
  沪股通为蓝色标签、机构专用为紫色标签。

## 目录结构

```
├── .github/workflows/fetch-lhb.yml   # 定时抓取工作流（UTC 12:00 / 12:30 = 北京 20:00 / 20:30）
├── scripts/fetch_lhb.py              # 抓取脚本（仅标准库，东财数据中心接口）
├── data/
│   ├── index.json                    # 归档索引（历史页数据源）
│   └── YYYY-MM-DD.json               # 每个交易日一份榜单数据
├── assets/
│   ├── style.css                     # 样式
│   ├── common.js                     # 共享工具（金额格式化、席位渲染、交互）
│   ├── home.js                       # 今日页逻辑
│   ├── history.js                    # 历史页逻辑
│   └── detail.js                     # 详情页逻辑
├── index.html / history.html / detail.html
└── .nojekyll
```

## 本地使用

```bash
# 抓取今天
python scripts/fetch_lhb.py
# 抓取指定日期（补历史）
python scripts/fetch_lhb.py 2026-08-27
# 强制重抓
python scripts/fetch_lhb.py 2026-08-27 --force
```

抓取后 data/ 下生成当日 JSON 与 index.json，直接以静态服务器打开 index.html 即可本地预览（如 `python -m http.server`）。

## 说明

- 数据源：东方财富数据中心公开接口（原始出处为沪深交易所"交易公开信息"），仅用于个人学习研究。
- 每个交易日 20:00 主抓一次，20:30 补抓一次，兼顾数据延迟。
- 深股通买入标注依据席位名包含"深股通专用"判断。
